## 🚀 Featured Projects

### ⚡ Payment Pipeline Health Monitor
> *Detecting silent payment failures before merchants notice*

A real-time fintech operations dashboard monitoring 5,000+ payment transactions, detecting silent pipeline failures, scoring merchant risk, and generating AI-powered intelligence reports using Groq LLaMA.

**The problem it solves:** After speaking with a Datadog account executive working with fintech companies at scale, I learned that most payment teams discover pipeline failures *reactively* — when merchants complain. This system flips that equation by detecting failures proactively.

**Key capabilities:**
- 🔇 **Silent Failure Detection** — catches transactions that fail with no alert triggered
- 🏪 **Merchant Risk Scoring** — scores each merchant 0–100 based on failure patterns
- ⚡ **Pipeline Stage Analysis** — identifies bottlenecks across gateway, bank auth, and processing stages
- 🤖 **AI Intelligence Reports** — Groq LLaMA generates plain English analysis the way a senior payments analyst would write it
- 📊 **Interactive Filters** — real-time filtering by merchant category, payment method, amount range, and date
